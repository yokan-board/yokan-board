# AGENT RULES

Review @docs/OVERVIEW.md and this codebase to understand how the app is implemented.

Before starting, acknowledge these guidelines:

- Work in a git branch and NEVER directly in the main branch.
- NEVER commit any changes in the branch until I ask you explicitly to do this.
- NEVER merge any changes to main until I ask you explicitly to do this.
- Before implementing any requested changes, ALWAYS create and let me review your plan on how to implement the changes.
- If any requested changes turns out to be complex, ALWAYS alert me and create a phased implementation plan.
- Each phase of an implementation plan MUST result in a working app, even though a feature may not be fully implemented.

Review and acknowledge that you understand and will adhere to these rules.
